# Tinywhoop type drone (cheapest,lightest,smallest and high quality)
This is a Drone project having these goals    
1.Cheap  
2.Light  
3.Small  
4.High quality  
5.Replicable  
This drone will be under 250 grams so you don't need a pilot license to fly it,It will have a 3d printed frame,A not ugly look
**THIS IS NOT A FPV DRONE**,It is not to built to handle stunts,It does not have a camera and isn't designed to,It is made just for the purpose of learning and fun
More will be added here as project progresses
